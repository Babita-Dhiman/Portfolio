# Babita Dhiman — Frontend Developer Portfolio

Modern, responsive personal portfolio built with **React + Vite + Tailwind CSS**.

## Features
- Dark theme with smooth animations
- Typewriter effect in hero section
- Active section highlighting in navbar
- Project showcase with live demo & source links
- Skills, Experience, Education, Services sections
- Fully responsive (mobile-first)

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Framer Motion (for animations)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
